# Documentación

| Carpeta | Contenido |
|---|---|
| `diagramas/Aplicaciones/` | Diagrama de aplicaciones en tres capas (`.drawio.svg` y `.drawio.png`, editables en draw.io) |
| `diagramas/Clases/` | Diagramas de clases en Mermaid (`.mmd`), uno por paquete: dominio y motores, método exacto, algoritmo genético, análisis, servicios y persistencia, presentación |
| `diagramas/secuencia/` | Diagramas de secuencia en Mermaid (`.mmd`): parametrización, comparación, método exacto, algoritmo genético y sensibilidad |
| `diagramas/MerYDicc/` | Modelo entidad-relación y diccionario de datos de la base SQLite (PDF) |
| `informe/` | Versiones exportadas del informe técnico en formato IEEE |

Los archivos `.drawio.svg` y `.drawio.png` llevan el diagrama por dentro: se abren y editan
directamente en draw.io o en app.diagrams.net. Los `.mmd` se pueden pegar en draw.io
(Organizar > Insertar > Avanzado > Mermaid) o en mermaid.live.
