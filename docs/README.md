# Documentación

| Carpeta | Contenido |
|---|---|
| `diagramas/clases/` | Diagrama de clases de la capa de lógica (draw.io y PNG) |
| `diagramas/secuencia/` | Diagramas de secuencia en Mermaid (`.mmd`) y PNG |
| `diagramas/aplicaciones/` | Diagrama de aplicaciones en tres capas (draw.io y PNG) |
| `bocetos/` | Bocetos de las cuatro pantallas (SVG importables a Figma y PNG) |
| `informe/` | Material del informe técnico en formato IEEE |

Los archivos `.drawio` se abren en draw.io o en app.diagrams.net. Los `.mmd` se pueden
pegar en draw.io (Organizar > Insertar > Avanzado > Mermaid) o en mermaid.live.
